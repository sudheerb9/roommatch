# Roommatch
# Project Description
RoomMatch is a web-based platform that helps college students find compatible roommates based on lifestyle preferences and living habits. Users authenticate using their university Google accounts and create profiles describing preferences such as sleep schedules, cleanliness, study habits, and noise tolerance.

The platform calculates compatibility scores between students and recommends potential roommate matches. Students can explore suggested matches, interact with other students, and form private roommate groups.

Groups can also define housing preferences such as the number of bedrooms or preferred housing features. Once a group is finalized, the system automatically assigns a compatible housing unit based on those preferences.

RoomMatch provides a structured and data-driven approach to roommate selection, helping students form better living arrangements and improving the traditional housing assignment process.

# Features
The RoomMatch system will include the following major features: 
1. Google-Based Authentication - Students authenticate using their university Google account. Access is restricted to users with a valid umass.edu email address.
2. User Profile Creation and Management - Students can create and update personal profiles, including lifestyle preferences such as sleep schedule, cleanliness habits, study preferences, and noise tolerance.
3. Preference-Based Matching System - The platform recommends compatible students using a compatibility score calculated from individual lifestyle preferences.
4. Student Match Discovery - Students can browse a list of recommended students ranked by compatibility score and initiate interaction.
5. Private Group Formation and Management - Students can create private roommate groups and manage group membership through invitations.
6. Group-Based Matching - Groups can search for and view students whose preferences are compatible with the group.
7. Housing Unit Preferences - Groups can define housing preferences such as number of bedrooms, number of bathrooms, floor level, corner units, window views, or buildings with facilities such as laundry.
8. Automatic Housing Assignment - When a group declares itself ready, the system automatically assigns a compatible housing unit based on the group’s preferences.
9. Housing Unit Management - Administrators manage the list of available housing units within the system.
10. Group Notification System - Members of a group receive notifications when a group member sends an invitation to another student and when a student accepts and joins the group.
